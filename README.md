# Judge on NEAR

Work in progress for NEAR HACKATHON (Nov 1 to 14, 2026).

An escrow on NEAR that pays a worker only when a deterministic judge, run through OutLayer's TEE workers, says the
delivery passed the terms frozen into the job. Anyone can re-run the same checks and get the same verdict.

Prior work: the checks are ported from the MIT-licensed JavaScript engine of Judge Protocol
(https://github.com/vijaygopalbalasa/judge-protocol). Everything NEAR-specific in this repository is new work written
during the hackathon.
