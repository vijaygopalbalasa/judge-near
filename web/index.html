Verify a Judge on NEAR ruling

Paste a NEAR testnet transaction that asked OutLayer to run the judge. This page downloads the exact wasm OutLayer ran, checks its SHA-256, runs it here on the same input, and compares the verdict with the one on chain. Nothing is sent anywhere except read requests to the NEAR RPC and the wasm URL.
